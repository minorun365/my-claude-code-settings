# チャットパネルでの出力の形

Claude Code をデスクトップアプリのチャットパネルで使う前提の書き方。パネルの横幅は40〜60文字程度と考える。

## コードブロックの使い分け

- 長い日本語の文章（原稿の案・書き換え案・引用）はコードブロックで囲まない。コードブロックの中は折り返されず、狭いパネルでは見切れる。引用（`>`）か通常の段落で見せる。
- コードブロックを使うのは、コマンド、ソースコード、ログやエラーの出力、外部へ送る文面だけにする。

## Before / After

チャットでは Before と After を縦に並べた引用で見せる。左右に並べる形は、横幅のある HTML でだけ使う。

## 表と箇条書き

表と箇条書きは、そのまま本文に書く。コードブロックや引用の中に入れない。

## URL

文中に URL を書くときは、前後に半角スペースを入れる。全角の括弧の直後に続けると、後ろの文字まで URL の一部として扱われることがある。
