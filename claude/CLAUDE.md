# Claude Code 固有の補足

AGENTS.md の共通ルールに加え、Claude Code だけに関わる運用を置く。詳細なルールは `rules/*.md` に分けてある。

## モデルと effort

- 設定ファイルはモデルごとに切り替えない。行動のルールは全モデル共通で AGENTS.md に書く。
- 考える量は effort の設定で決まる。「よく考えて」「考えずに」のような文は、設定ファイルにもプロンプトにも書かない。

## MCP の接続状況は「ツールが呼べるか」で判断する

`claude mcp list` の `✔ Connected` は、サーバーと通信できたことしか示さない。Connected と表示されていても、ツールが1つも使えないことがある。使えるかどうかは、実際にツールを呼んで確かめる。

## 並行セッションへの指示

自分が起こしたセッションへの指示や追加情報は、利用者に確認せずに送り、送ったことをチャットに1行で書く。確認を挟むと、相手のセッションが待ちで止まる。送り先に外部発信・削除・課金をさせる指示と、相手の作業を止めさせる指示だけは、先に利用者へ確認する。

## 定期実行の結果の出口

定期実行のルーチンを作るときは、結果を利用者が日常的に見る1か所へ出す。ターミナルのログや状態ファイルを出口にすると、動いていても誰にも届かない。出口のページは固定の1枚を上書きし、履歴は同じページに直近の数件だけ持たせる。
